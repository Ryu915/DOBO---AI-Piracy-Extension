🧠 Welcome to DOBO

DOBO helps you understand when your data is being transmitted from your browser to external systems — especially when using AI tools.

What DOBO Shows

  • 🔴 When a website sends network requests
  • ⚠️ Suspicious tracking or analytics domains
  • 🧠 ML-based domain risk prediction
  • 📊 Domain activity dashboard

How to Use

  • Open any website
  • DOBO will automatically monitor outgoing requests
  • View live activity in the floating monitor
  • Open the extension popup to see domain statistics

This tool provides transparency about network activity, but cannot inspect encrypted data contents.
